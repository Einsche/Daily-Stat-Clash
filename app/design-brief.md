# Daily Stat Clash

- Design read: A daily competitive anime character drafting game, focused on rapid, legible decisions and suspense.
- Concept spine: The arena draft terminal. One unseen challenger, six tactical slots, a midnight reveal.
- Delivery tier: editorial product interface, not an animated marketing landing.
- Animation mode: non-animated — transactional daily drafting requires predictable focus, legibility and quick return visits.
- Palette: #140F1A ink, #21182B raised surfaces, #F5EAF8 text, #E983A9 rose, #A7A0D3 periwinkle. Dark plum and soft rose mark irreversible card selection without neon.
- Type: system sans with sharp condensed tracking for display, generous labels for tactical data.
- Sections: compact masthead and date, draft arena, six-slot assignment grid, status and submission, competition leaderboard, match history, authentication overlay.
- Assets: framed original character portraits generated as distinct local SVG artwork; designed typographic monogram; hand-composed launch cover.
- Primary CTA: assign current character, animated feedback on slot acceptance.
- Secondary CTA: submit immutable six-slot lineup.
- Navigation: no nested distractions; scoreboard tabs, log history and account menu inline.
- Trust: no character stats from pending drafts serialized to browser. Day boundary Europe/Istanbul, server authoritative. Server reconciles completed days; scheduled ping recommended.
- Scoring: pair submitted accounts for the day, exactly six stat duels, +1 each win and 0 each tie, no duplicate score. Odd account receives BYE. Total score aggregates weekly/monthly/all time.
- Roster status: 101 original characters in 12 original fantasy realms, as a legal publishing substitute; not a replacement for the requested copyrighted-universe roster.
